# 🧪 Prompt Evaluation

## 🎯 Goal

Evaluate whether the customer service prompt can consistently generate professional, empathetic, and helpful responses across different customer complaints.

## 📊 Evaluation Criteria

| Criteria     | What I Look For                            |
| ------------ | ------------------------------------------ |
| 🤝 Empathy   | Acknowledges the customer's feelings       |
| 🛠️ Action   | Explains how the agent can help            |
| 👉 Next Step | Gives the customer a clear next step       |
| 🎯 Accuracy  | Does not invent information                |
| 💬 Tone      | Professional, calm, and respectful         |
| 📝 Clarity   | Uses simple and easy-to-understand English |

## 🧪 Test Results

### 📦 Late Order

**Result:** ✅ Good

The response acknowledged the customer's frustration, offered to check the order status, and requested an order or tracking number.

### 💰 Refund Request

**Result:** ✅ Good

The response showed empathy, offered help with the refund process, and requested the order number without promising that the refund would be approved.

### 📦 Damaged Product

**Result:** ✅ Good

The response acknowledged the problem and requested useful information such as the order number and photos without making unsupported promises.

### 😡 Angry Customer

**Result:** ✅ Good

The response remained calm and professional despite the customer's anger. It acknowledged the frustration and requested information needed to investigate the issue.

## 🏆 Overall Result

The prompt successfully generated consistent customer service responses across four different customer situations.

The responses followed the required structure, maintained a professional tone, and avoided inventing information.

## 🧠 What I Learned

I learned that giving an LLM a clear role, specific instructions, output structure, and constraints can make its responses more consistent.

Testing the same prompt with different customer situations also helped me evaluate whether the prompt works beyond a single example.
